# 가상 ABCP 거래 조건표

이 문서는 Codex 작성 흐름을 시험하기 위해 새로 작성한 가상 자료입니다.
실제 거래나 기관의 승인 내용을 나타내지 않습니다.

## 제공된 조건

| 항목 | 조건 |
|---|---|
| 문서 작성 기준일 | 2026-10-08 |
| 차주 | 새솔개발 주식회사 |
| ABCP 발행인 겸 기초자산대출 대주 | 한빛유동화제일차 주식회사 |
| 주선기관 | 가온금융 주식회사 |
| 거래 개요 | 발행인이 ABCP를 발행하여 조달한 자금으로 차주에게 운전자금 대출 실행 |
| 조달금액 / 기초자산대출 원금 | 300억원 |
| 실행일 | 2026-10-08 |
| 최종 만기일 | 2027-10-08 |
| 기초자산대출 금리 | 연 4.50%, 고정금리 |
| 대출 원금 상환 | 최종 만기일에 전액 일시상환 |
| 대출 이자 | 실제 경과일수/365 기준, 만기에 후취 |
| 담보 | 무담보 |
| 자금 용도 | 운전자금 |
| ABCP 발행 일정과 발행금리 | 미확정, 별도 협의 필요 |
| 주선수수료 | 미확정, 별도 협의 필요 |

## 문서 작성 조건

- 현재 제공된 조건을 정리한 협의용 초안이며, 확약 문서가 아닙니다.
- 대출금리 연 4.50%를 ABCP 발행금리로 바꾸거나 전체 비용률로 표시하지 않습니다.
- 금액, 금리, 회사명, 만기일을 임의로 수정하지 않습니다.
- 미확정 주선수수료 및 ABCP 조건은 명시하고 확인사항에도 남깁니다.
- 신용보강, 매입약정, 보증, 재무약정 등 제공되지 않은 조건을 만들어 넣지 않습니다.
- 기관 공통 문구는 같은 폴더의 `house.yaml`을 사용합니다.
- 본 자료에는 승인된 만기 이자액이나 영업일 조정 규칙이 없습니다.
  추정 이자액이나 조정된 만기일을 확정 조건으로 추가하지 않습니다.
