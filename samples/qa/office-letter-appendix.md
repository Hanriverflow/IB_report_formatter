# 운영자료 확인 및 보완 요청

1. 귀사의 업무 협조에 감사드립니다.
2. 귀사에서 제출한 운영자료를 검토한 결과, 일부 항목의 확인이 필요하여 붙임과 같이 보완을 요청드립니다. 확인 대상은 해당 자료의 관리번호와 담당 부서이며, 이미 확인이 끝난 항목은 다시 제출하지 않으셔도 됩니다.
3. 붙임의 확인 내역을 검토하시어 수정이 필요한 부분을 기재한 후, 2026년 9월 25일까지 담당자 전자우편으로 회신해 주시기 바랍니다.
4. 요청 내용이나 제출 일정에 관하여 협의가 필요한 경우 아래 담당자에게 연락해 주시기 바랍니다.

# 운영자료 확인 내역

## 확인 대상

아래 관리번호와 담당 부서의 일치 여부를 확인해 주시기 바랍니다. 관리번호 앞의 0은 코드의 일부이므로 삭제하지 않습니다.

| 관리번호 | 확인 항목 | 요청 사항 |
|---|---|---|
| 001234 | 운영실적 집계 | 담당 부서 확인 |
| 005678 | 설비 운영계획 | 변경 사유 기재 |
| 009012 | 인력 운영계획 | 제출 예정일 확인 |

## 회신 방법

확인 결과는 자료 보완 양식에 작성해 보내주시기 바랍니다. 변경 사항이 없는 항목에는 ‘변경 없음’으로 기재합니다.
